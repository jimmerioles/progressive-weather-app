# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, report them privately using this repository's
[private vulnerability reporting form](https://github.com/jimmerioles/progressive-weather-app/security/advisories/new) —
or go to the **Security** tab and click **"Report a vulnerability"**.

This creates a private advisory visible only to the maintainers and provides a structured
workflow for triage, fix coordination, and CVE assignment. All security vulnerabilities will be
acknowledged and promptly addressed.
